Architecture

image (3,128,128)                 text prompt
        │                               │
   ┌────▼─────┐                    ┌────▼─────┐
   │   ViT    │                    │  GPT.wte │  (text token embeds)
   │ +projector│                   └────┬─────┘
   └────┬─────┘                         │
   visual_embeds (64, 512)              │
        └──────────────┬────────────────┘
                       ▼
            combined_embeds (64 + T_text, 512)
                       ▼
              GPT transformer (causal, depth 8)
                       ▼
                 logits → loss / next token

The image is encoded into a fixed 64-token visual prefix (128/16 = 8×8 patches) that is concatenated ahead of the text embeddings and fed through the causal LLaMA transformer.

4. Evaluation — Image Description

The final SFT checkpoint (vlmsft_d8) was run on 6 held-out COCO val2014 images with the prompt "Describe this image." (temperature 0.7). The model reliably produces fluent, grammatical, image-conditioned captions in the COCO caption style. Subject accuracy is partial — a direct consequence of the 54M-parameter scale and 82M-token base — but the vision→language path is clearly functional (e.g. both tennis images → tennis, the bear image → bears).

Reading the results. Every output is a well-formed, fluent English caption that terminates cleanly on <|assistant_end|> — the SFT objective is being met. The model has learned the COCO caption distribution and conditions on the image (tennis images consistently yield tennis captions). Exact subject identification is unreliable because the base LLM saw only ~82M tokens and the ViT is a 4-layer / 256-dim encoder. Scaling up the base model and ViT (and/or initializing the ViT from a pretrained checkpoint) is the clear path to higher accuracy.

5. Bugs Found & Fixed During the Run

Six issues were encountered and fixed to get a working end-to-end model:

1. Base train batch-size assertion
--total-batch-size is in tokens and must be a multiple of device_batch_size × max_seq_len (32×512 = 16384). Initial value 512 failed the assert. Fixed by using --total-batch-size=16384.
2. COCO captions URL 404
captions_val2014.json is not hosted standalone. Fixed scripts/coco_data.py to download annotations_trainval2014.zip and extract annotations/captions_val2014.json from it.
3. Nested image extraction
val2014.zip extracts into val2014/val2014/. Added a flatten step, and made the image download skip when the directory is already populated (avoids a 6.6 GB re-download).
4. COCODataset UnboundLocalError
The train branch referenced start, which was only defined in the val branch. Fixed by computing split_point before the branch.
5. SFT target shape mismatch
targets[i] (length max_len) was assigned a shifted tensor of length max_len-1. Fixed by assigning to targets[i, :max_len-1].
6. Muon optimizer on 4-D Conv2d weight
setup_optimizer routed the ViT's 4-D patch_embed Conv2d weight to Muon (which only supports 2-D matrix params), causing a buffer shape mismatch under torch.compile. Fixed the routing condition from param.ndim >= 2 to param.ndim == 2, sending the Conv2d weight and 3-D pos_embed to AdamW.

7. How to Reproduce

cd nanochat-vlm && source .venv/bin/activate

# 0. Data + tokenizer
python -m nanochat.dataset -n 5                 # base text shards
python -m scripts.tok_train --max-chars 300000000 --vocab-size 8192
python -m scripts.coco_data                     # COCO val2014 images + captions

# 1. Base LLM
CUDA_VISIBLE_DEVICES=0 python -m scripts.base_train \
    --depth=8 --max-seq-len=512 --device-batch-size=32 \
    --total-batch-size=16384 --num-iterations=5000 \
    --eval-tokens=512 --core-metric-every=-1 --model-tag d8

# 2. Stage 1: ViT pretrain (frozen LLM)
CUDA_VISIBLE_DEVICES=0 python -m scripts.vit_pretrain \
    --model-tag d8 --num-iterations=3000 --eval-every=300 \
    --device-batch-size=16 --total-batch-size=256 --vit-lr 0.0003

# 3. Stage 2: VLM SFT (full fine-tune)
CUDA_VISIBLE_DEVICES=0 python -m scripts.vlm_sft \
    --source vlm --model-tag vlm_d8 --num-iterations=3000 \
    --eval-every=300 --device-batch-size=16 --total-batch-size=256

# 4. Inference
python -m scripts.vlm_cli --image photo.jpg --prompt "Describe this image." \
    --source vlm_sft --model-tag vlmsft_d8 --temperature 0.7

8. Suggested Next Steps

  • Scale up the base LLM (more tokens / depth) for stronger caption content.
  • Initialize the ViT from a pretrained encoder (e.g. DINOv2) instead of from scratch.
  • Save the best-validation checkpoint during SFT (currently only the final step is saved; min val was at step 1500).
  • Add a proper captioning metric (CIDEr / SPICE) on a held-out COCO split.
  • Support multi-image and variable-resolution inputs.
